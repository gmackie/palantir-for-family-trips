## Why this matters

`suncalc` and `@googlemaps/polyline-codec` are declared in the **root**
`package.json` dependencies, but they are imported only by
`packages/api/src/router/route-planner.ts`. Root-level runtime deps blur which
workspace package actually owns a dependency, can mask a missing dependency in
`@sortey/api` (it resolves via hoisting today, which would break if the API
package were consumed standalone), and make the dependency graph harder to
reason about. Moving them to the package that uses them is the monorepo
convention.

  If it exists at the root, it moves alongside `suncalc` into
  `packages/api`'s `devDependencies`.
