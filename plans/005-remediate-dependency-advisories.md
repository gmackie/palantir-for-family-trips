## Why this matters

`pnpm audit --prod` reports 16 advisories, all transitive. The ones that matter sit on three chokepoints: **better-auth 1.6.11** (pulls solid-js → `seroval` ≤1.4.0, which carries an RCE-class deserialization advisory plus prototype-pollution and DoS advisories, on the path `apps/expo > better-auth > solid-js > seroval`), **uploadthing ^7.7.4** (pulls `h3` <1.15.6 — SSE injection — and `effect` <3.20.0 — AsyncLocalStorage context loss under concurrency, path `packages/storage > uploadthing > …`), and **react-devtools-core** (pulls vulnerable `shell-quote`; dev-tooling path via react-native). Reachability of each vulnerable code path from this app is unverified — the honest framing is hygiene on auth/upload/RN chokepoints plus confirmation that the devtools path is dev-only — but the fix is mechanical version bumps, so the cost of clearing them is low.
