## Why this matters

Receipt uploads migrated to Cloudflare R2: the live path is
`apps/nextjs/src/app/api/receipts/upload/route.ts` →
`~/lib/receipt-storage` + `@sortey/db/runtime` (`getR2Bucket`). The
`uploadthing` dependency now survives only inside
`packages/storage/src/index.ts`, and **nothing imports `@sortey/storage`** at
all (verified: `grep -rln "@sortey/storage"` across `packages` and `apps`
returns only `packages/storage/package.json` itself). So the dependency is dead
weight that still pulls the advisory-laden `uploadthing → h3` subtree into the
install graph (`pnpm audit` flags `h3` SSE injection via this path). Removing it
shrinks the dependency surface and clears the advisory.
